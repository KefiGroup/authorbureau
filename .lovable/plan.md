

# Redesign BP-09 — From "Book Sales Kit" to **Live Audience Conversion Toolkit**

## What you're asking for
Today BP-09 generates a generic "buy the book" sales page + Stripe link. That overlaps with what BP-07/08 already do, and it doesn't actually help authors **convert live audiences** at workshops, book signings, and corporate lunches — which is where most non-fiction authors make their real money on the day.

Pivot BP-09 so Abby produces the **field kit an author actually walks into the room with**: a sales pitch, slide deck, signing-table script, and corporate-lunch talk track — all personalised to their book's framework.

## New BP-09 deliverables (replaces the current event strategy/pricing tier output)

For each of the **3 venue types** below, Abby generates a complete conversion package:

### A. Workshop Back-of-Room (60–90 min teaching session)
- **Talk outline** — 5-section structure (Hook → Story → Framework teach → Live exercise → Offer)
- **Slide deck** — 12–15 slides (title, 3 pain slides, 3 framework slides, 2 case-study slides, exercise slide, offer slide, QR slide, thank-you) with on-slide copy + speaker notes
- **Pitch script** — word-for-word 3-minute "transition to offer" script that bridges teaching → book sale
- **Back-of-room close** — what to say while standing at the table, top 5 objection responses
- **One-page handout** — printable PDF outline + QR code to buy

### B. Book Signing & Fireside Q&A (intimate, bookstore/library, 30–45 min)
- **Reading selection guide** — which 2–3 passages to read, why, and the talking-point bridge between each
- **Q&A seed questions** — 8 pre-planted questions with author's polished answers (so Q&A never dies)
- **Signing-table script** — the 30-second script for each person in line (name capture + one question + signed inscription template)
- **Inscription templates** — 5 personalised dedications keyed to reader type (e.g. "for the dreamer", "for the rebuilder")
- **Email-capture flow** — exact words to ask for the email, what they get in return

### C. Corporate Lunch & Learn (45–60 min, paid speaking or free + book bulk)
- **Corporate pitch deck** — 10 slides framed in business-outcome language (productivity, leadership, retention)
- **ROI talking points** — 3 metrics that decision-makers care about, mapped to the book's framework
- **Bulk-order proposal one-pager** — pricing tiers (10 / 50 / 200 books), what's included at each, signed copies, optional 30-min follow-up Q&A
- **Follow-up email sequence** — 3 emails to the HR/L&D contact (24h thank-you, 1-week ROI recap, 2-week proposal)

### Shared assets (one set, reused across all 3 venues)
- **Author bio — 30 sec / 60 sec / 2 min versions** for the host's introduction
- **3-line elevator pitch** for impromptu networking
- **5 standard objection responses** ("I'll buy on Amazon later" / "I don't read much" / "Too expensive" / etc.)
- **Lead capture QR** — links to the existing BP-02 lead magnet (auto-detected if live)

## Where the output lives

| Asset | Format | Where |
|---|---|---|
| Talk outlines, scripts, Q&A, objections | Editable cards in the builder | Saved to `content_json` |
| Slide decks (3 total) | Downloadable .pptx + Google Slides–ready HTML | Generated by edge function on demand |
| Handouts & one-pager proposals | Downloadable PDF | Generated on demand |
| Inscription templates, elevator pitch | Quick-copy cards (one-click to clipboard) | In builder |
| Public sales page | **Removed** — BP-07/08/09 (book direct buy) already cover this; BP-09 is now an *internal* author toolkit, not a public microsite |

This matches the BP-06/07/08 pattern of "asset library, not microsite" but extended with **export-ready slide decks** and **printable handouts**.

    "elevator_pitch": "...",
    "objection_responses": [{ "objection": "...", "response": "..." }]

  "workshop": {

  },
  "book_signing": {
    "reading_passages": [{ "chapter": "...", "why": "...", "bridge_to_next": "..." }],
    "qa_seed_questions": [{ "q": "...", "a": "..." }],

    "inscription_templates": [{ "for": "the dreamer", "text": "..." }],

  },

    "slides": [{ "n": 1, "title": "...", "body": "...", "speaker_notes": "..." }],

Prompt grounds everything in `author_context.book_title`, `core_thesis`, `key_frameworks`, `target_audience_persona` and the author's pen name. Model: `openai/gpt-5.2`, `max_completion_tokens: 12000` (this is a complex structure — per `complex-structure-generation-reliability` memory). No temperature override (per `manus-2026-04-23` audit memory).

### 2. New edge function: `supabase/functions/export-bp09-slides/index.ts`
- Input: `{ author_id, deck: "workshop" | "corporate_lunch" }`
- Reads `content_json.workshop.slides` (or `corporate_lunch.slides`)
- Generates a `.pptx` using `pptxgenjs` (npm via esm.sh) — title slide + content slides + speaker notes
- Returns base64 .pptx for download
- Branded with author's pen name + book title in the master slide

### 3. New edge function: `supabase/functions/export-bp09-handout/index.ts`
- Input: `{ author_id, document: "handout" | "bulk_proposal" }`
- Generates a clean printable HTML → returned as a downloadable PDF (or HTML that prints well)
- Branded footer: "Powered by Authors Bureau"

### 4. `deploy-bp09-to-ghl/index.ts` (existing)
- Strip the Stripe product/payment-link creation. BP-09 no longer sells a product; it's an internal toolkit.
- Reduce to: mark node `status='live'`, save `content_json`, set `microsite_url = null` (or skip).
- Or simply replace this function call with a direct `publishNodeToSite` write — no GHL/Stripe needed.

### 5. Database
No schema changes. `author_nodes.content_json` already accepts arbitrary JSON. Existing BP-09 rows will get re-generated content the next time the author runs the builder; old field shapes are simply ignored by the new UI.
