# Sprint 2 — Fix Doc 03 (Node Activation Prompts)

## Problem

`docs/03-abby-node-activation-prompts.md` was generated by `scripts/build-docs.mjs`, which only matched prompts assigned to top-level `const`/`let`/`var` template literals. 25 of the 29 generator functions build their prompts inline inside `fetch(...)` `messages: [{ role, content: \`...\` }]` arrays, so the regex skipped them and produced "No template-literal prompts auto-detected".

All 29 generator edge functions exist on disk (verified via `ls supabase/functions/generate-*`). None need to be marked "Edge function not yet built."

## Approach

Manually extract the `system` and `user` prompt strings (verbatim, including `${...}` template variables) from each of the 25 affected edge functions and rewrite their sections in Doc 03. The 4 already-correct sections (BP-01, BP-02, BP-04, BP-05) stay as-is.

Then update `scripts/build-docs.mjs` so future auto-builds also match the inline `messages: [{ role: "...", content: \`...\` }]` pattern, preventing the regression. After that, re-run the build script and re-zip `/mnt/documents/authors-bureau-docs-v2.zip`.
