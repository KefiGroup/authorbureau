

# Add Amazon Author URL for Felicia Tan

## What Changes

A single line addition in `src/data/authors.ts` to add the `amazonAuthorUrl` field to Felicia Tan's author record.

## Technical Details

**File**: `src/data/authors.ts`

Add the following field to Felicia Tan's entry (alongside her existing `websiteUrl` and `linkedinUrl`):

```
amazonAuthorUrl: "https://www.amazon.com/stores/Felicia-Tan/author/B0GNDPGKL2"
```

This will make the Amazon Author link appear on her author profile and book microsite pages, matching how Pauline Teo and Robert Battista already have their Amazon Author URLs configured.
