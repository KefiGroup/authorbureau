

## Fix: Build the Actual Quiz Flow

The quiz data (8 questions, scoring tiers, result tips) is already generated by Abby and stored in `content_json`. It just never gets rendered.

### Correct Flow (4 stages)

```text
Stage 1: GATE        → Name + Email form (as-is)
Stage 2: QUIZ        → 8 multiple-choice questions, one at a time
Stage 3: RESULTS     → Score, tier name, personalised tips from the book
Stage 4: NEXT STEP   → CTA to buy book / follow author
```

### What Changes

**File: `src/pages/MicrositePage.tsx` — `LeadMagnetPage` component**

1. Add state machine: `stage` = `"gate"` | `"quiz"` | `"results"`
2. Add `currentQuestion` index and `answers` array state
3. On form submit (gate) → set stage to `"quiz"` (instead of `submitted = true`)
4. Render quiz UI: progress bar, question text, 4 answer options as clickable cards
5. On answer click → record answer, advance to next question
6. After question 8 → calculate score by summing answer indices, map to the correct `scoring_tier`
7. Render results: tier name, score visualisation, personalised tips array, book CTA
8. Keep the contact submission (microsite-action) firing at the gate stage so the lead is captured

### Quiz UI Design
- Progress bar showing "Question 3 of 8"
- Large question text
- 4 answer options as full-width cards (tap-friendly on mobile)
- Subtle animation between questions
- Results page: coloured tier badge, score bar, 3-4 tip bullets, "Get the Book" CTA

### Data Structure (already in content_json)
- `quiz_structure.questions[].question` — the question text
- `quiz_structure.questions[].options[]` — 4 answer strings
- `quiz_structure.scoring_tiers[]` — { name, range, description, tips[] }

### No backend changes needed
All quiz logic runs client-side. The contact was already captured at Stage 1.
