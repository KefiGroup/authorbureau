# AuthorsBureau.com — ABBY Framework v3.0: Strategy + Content + Connect

## Core Principle
**Authors Bureau is the strategic brain, not the production factory.** One book manuscript fuels Abby's AI consultation, which generates high-value content assets. Authors then deploy those assets through best-in-class external tools (connectors), guided step-by-step by Abby.

## The ABBY Framework: Analyze, Build, Bridge, Yield

### Center
- Published Book (Foundation)
- Author Microsite (Free, built-in)
- Author Profile (Free, built-in)

---

## 3-Phase Workflow Per Node

Every node follows the same pattern:

### Phase 1: ANALYZE — Abby's Strategic Consultation
Abby reads the manuscript, understands the author's goals, audience size, and market position, then delivers a tailored execution plan with pricing strategy, positioning, and timeline.

### Phase 2: BUILD — AI Content Generation
AI generates the actual content assets: scripts, outlines, curricula, calendars, slide decks, pitch kits, sales pages, workbooks, etc. Author reviews, edits, and approves.

### Phase 3: BRIDGE — Connect to External Tools
Abby recommends tiered tools (Free → Pro) and provides:
- Step-by-step setup instructions
- "Format for [Tool]" export buttons where applicable
- Generic exports (Markdown, PDF, CSV) always available
- Direct hyperlinks to recommended platforms

## CRM: Automated Marketing Sequences

### Sequence A: Reader → Student (Marketing → Revenue)
Book purchase → 7 days → "Dive deeper with the online course" → 3 days → Course discount offer

### Sequence B: Student → Coaching Client (Revenue → Revenue)
Course 80% complete → "Ready to implement? Coaching accelerates results" → If clicked, tag coaching_lead

### Sequence C: Coaching Client → Speaker Audience (Revenue → Authority)
Coaching complete → "Join next live event" → Event invitation

### Sequence D: Event Attendee → Mastermind/Certification (Authority → Revenue)
Event attended → 14 days → "Take your journey to next level" → Mastermind/Certification application

### Sequence E: Cross-Author Promotion
Reader finishes book → "Readers who loved [Book] also discovered..." → Recommend other authors

### Sequence F: Re-engagement
No activity 30 days → "We miss you! Here's what's new" → Latest content + events

## Key Architecture Rules
- All products link to `book_id` as source
- All customer interactions feed into CRM
- `generated_assets` stores raw AI output; structured data populates domain tables
- Every asset has status: draft → approved → published
- Authors Bureau generates content; external tools handle delivery/hosting
- Phase 3 (Bridge) provides guided setup, not built-in tooling
