> Canonical source: see [Master Architecture Reference](../01-architecture/01-master-architecture-reference.md) §3 for the full registry.

---

## 1. What it is

Customised corporate training programmes built from the book's framework. 8-step workflow includes Bloom's taxonomy + Kolb's stages alignment.

## 2. What ABBY builds

Engines: **Sessions + Commerce**. ABBY generates training menu, learning outcomes (`blooms_level`), experiential mapping (`kolbs_stage`), proposal templates (per `mem://features/training-program-comprehensive-specs`).

## 3. What the author does

1) Open YR-22 builder (8 steps). 2) Define audience + outcomes. 3) Generate curriculum. 4) Set price. 5) Optionally connect Thinkific. 6) Activate.

## 4. What the reader experiences

L&D buyer requests proposal → contract → delivery (live or Thinkific) → evaluation.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND commerce signal AND (`session_type` OR `booking_url` — session-style).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $5k–$75k per engagement.

## 7. Dependencies

Stripe; optional Thinkific.

## Technical Appendix

### 8. `content_json` schema

```typescript
{
  title: string;
  programs: Array<{
    id; title; audience; duration_days;
    modules: Array<{ title; blooms_level; kolbs_stage; outcomes }>;
    price_usd; stripe_price_id?;
  }>;
  session_type: "in_person"|"virtual"|"hybrid";
  booking_url?: string;
  proposal_template: string;
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
