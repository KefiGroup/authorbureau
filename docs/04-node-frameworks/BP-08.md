# BP-08 · Special Editions

_Version 3.2 · 2026-05-01_

**Category:** Brand Products  
**Scope:** Book-level  
**Primary edge function:** `supabase/functions/generate-bp08-special-editions/index.ts`

> Canonical source: see [Master Architecture Reference](../01-architecture/01-master-architecture-reference.md) §3 for the full registry.

---

## 1. What it is

Limited-edition, signed, or themed special editions of the book — physical or digital scarcity products.

## 2. What ABBY builds

Engine: **Commerce**. ABBY drafts edition concept, sales page, scarcity copy, calendar of release windows (`special-edition-calendar.ts`).

## 3. What the author does

1) Open BP-08 builder. 2) Approve edition concept + sales page. 3) Set price + inventory cap. 4) Activate.

## 4. What the reader experiences

Reader buys → physical fulfilment via author's chosen logistics OR digital download.

## 5. Readiness gate (`hasRequiredAssets`)

Generic gate — non-empty `content_json` passes.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $39–$199 per edition.

## 7. Dependencies

BP-09 sales channel. Sprint 50 renamed the generator folder from `generate-bp08-mastermind` → `generate-bp08-special-editions`.

## Technical Appendix

### 8. `content_json` schema

```typescript
{
  edition_id: string;
  edition_name; concept; release_window: { start; end };
  inventory_cap: number;             // null = unlimited
  bonus_content?: Array<{ type; url }>;
  sales_page: { hero; scarcity_copy; cta };
  stripe_price_id?: string;
  price_usd?: number;
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
