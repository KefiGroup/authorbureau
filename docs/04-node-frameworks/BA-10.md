---

## 1. What it is

The author's flagship self-paced online course — the highest-ticket Brand-tier product before YR offers.

## 2. What ABBY builds

Engines: **Course + Commerce**. ABBY drafts a multi-module curriculum with lessons, optionally exports to Thinkific.

## 3. What the author does

1) Open BA-10 builder. 2) Approve modules. 3) Build lessons. 4) Optionally connect Thinkific. 5) Set price. 6) Activate.

## 4. What the reader experiences

Reader buys → enrolment → `MemberPortalPage` (or Thinkific subdomain).

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND (`course_id` set OR ≥ 1 module OR commerce signal).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $297–$1,997.

## 7. Dependencies

BP-06 + BP-07 (per product development sequence). Optional: Thinkific.

## Technical Appendix

### 8. `content_json` schema

```typescript
{
  title: string;
  course_id?: string;                // FK → courses.id
  modules: Array<{ id; title; lessons: Array<{ id; title; video_url?; pdf_url?; quiz_id? }> }>;
  thinkific_subdomain?: string;
  stripe_price_id?: string;
  price_usd?: number;
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
