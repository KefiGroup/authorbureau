High-value consulting engagements — typically multi-month strategic advisory.

## 2. What ABBY builds

Engine: **Commerce**. ABBY drafts service tiers, application form, proposal template. Generator's NODE_NAME is 'Big Ticket Offers' — canonical label is 'Big Ticket Consulting'.

## 3. What the author does

1) Open YR-20 builder. 2) Define tiers. 3) Set price. 4) Activate.

## 4. What the reader experiences

Buyer applies → discovery call → contract → engagement.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND commerce signal.
