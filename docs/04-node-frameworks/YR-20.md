# YR-20 · Big Ticket Consulting

_Version 3.2 · 2026-05-01_

**Category:** Yield Revenue  
**Scope:** Author-level  
**Primary edge function:** `supabase/functions/generate-yr20-big-ticket/index.ts`

> Canonical source: see [Master Architecture Reference](../01-architecture/01-master-architecture-reference.md) §3 for the full registry.

---

## 1. What it is

High-value consulting engagements — typically multi-month strategic advisory.

## 2. What ABBY builds

Engine: **Commerce**. ABBY drafts service tiers, application form, proposal template. NODE_NAME resolves dynamically via `getCanonicalNodeLabel('YR-20')` → 'Big Ticket Consulting' (Sprint 51 replaced legacy 'Big Ticket Offers').

## 3. What the author does

1) Open YR-20 builder. 2) Define tiers. 3) Set price. 4) Activate.

## 4. What the reader experiences

Buyer applies → discovery call → contract → engagement.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND commerce signal.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $10k–$100k+ per engagement.

## 7. Dependencies

Stripe (or invoicing).
