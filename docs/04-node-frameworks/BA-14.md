# BA-14 · Podcast Tour

_Version 3.1 · 2026-05-01_

**Category:** Build Authority  
**Scope:** Author-level  
**Edge function:** `supabase/functions/generate-ba14-podcast/index.ts`

> Canonical source: see [Master Architecture Reference](../01-architecture/01-master-architecture-reference.md) §3 for the full registry.

---

## 1. What it is

The author's own podcast hosted on Transistor.fm, distributed via RSS to Spotify / Apple. One show per author.

## 2. What ABBY builds

Engine: **Podcast**. ABBY generates a season arc (`generate-podcast-season`) with episode topics, then per-episode outlines.

## 3. What the author does

1) Open BA-14 builder. 2) Approve season arc. 3) Record + upload via Transistor. 4) Activate when ready.

## 4. What the reader experiences

Listener subscribes via Spotify / Apple → RSS delivers new episodes.

## 5. Readiness gate (`hasRequiredAssets`)

RSS ready (`rss_url` / `rss_feed_url` / `transistor.show_id`) AND ≥ 1 episode, OR activated + ≥ 2 episodes + show title.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Indirect — discovery + authority. Optional sponsorship.

## 7. Dependencies

Transistor.fm (platform-managed).
