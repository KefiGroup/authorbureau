# YR-28 · Sponsors

_Version 3.2 · 2026-05-01_

**Category:** Yield Revenue  
**Scope:** Author-level  
**Primary edge function:** `supabase/functions/generate-yr28-sponsors/index.ts`

> Canonical source: see [Master Architecture Reference](../01-architecture/01-master-architecture-reference.md) §3 for the full registry.

---

## 1. What it is

Author-side sponsorship sales — podcast sponsorships, newsletter sponsorships, conference sponsorships.

## 2. What ABBY builds

Engine: **Commerce**. ABBY drafts sponsor deck, rate card, prospect list, outreach emails. NODE_NAME resolves dynamically via `getCanonicalNodeLabel('YR-28')` → 'Sponsors' (Sprint 52 replaced legacy 'Sponsors & Exhibitors').

## 3. What the author does

1) Open YR-28 builder. 2) Set inventory + rates. 3) Approve deck. 4) Activate. 5) Outreach manually.

## 4. What the reader experiences

Sponsor (B2B buyer) reviews deck → buys placement → receives reporting.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND commerce signal.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $500–$25k per placement.

## 7. Dependencies

BA-14 (podcast inventory), BP-01 (newsletter inventory), YR-26 (conference inventory).

```typescript
{

  outreach_email_template: string;
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
