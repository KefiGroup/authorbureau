_Version 3.2 · 2026-05-01_

**Category:** Brand Products  
**Scope:** Book-level

> Canonical source: see [Master Architecture Reference](../01-architecture/01-master-architecture-reference.md) §3 for the full registry.

---

## 1. What it is

A self-paced video / PDF course delivered as the book's mid-tier upsell. Sits between Workbook (BP-06) and Online Course (BA-10).

## 2. What ABBY builds

Engines: **Course + Commerce**. ABBY drafts module → lesson outline using the book's framework. Curriculum-aware sales copy via Standardized Sales Page Builder.

## 3. What the author does

1) Open BP-07 builder. 2) Approve curriculum. 3) Add lesson assets. 4) Set price. 5) Activate.

## 4. What the reader experiences

Reader buys → enrolment row in `course_enrollments` → `MemberPortalPage` access → progress tracked.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND (`course_id` set OR commerce signal).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $97–$297.

## 7. Dependencies

BP-06 (must precede per `mem://business/product-development-sequence`). Sprint 50 renamed the generator folder from `generate-bp07-coaching` → `generate-bp07-home-study`.

### 8. `content_json` schema

```typescript
{
  title: string;
  course_id?: string;                // FK → courses.id
  modules: Array<{ id; title; lessons: Array<{ id; title; type; asset_url? }> }>;
  sales_page: { hero; problem; framework; modules_preview; testimonials; cta };  // 11-section
  stripe_price_id?: string;
  price_usd?: number;
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
