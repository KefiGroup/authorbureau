## 1. What it is

A self-paced course version of the book's framework — videos, audio, and worksheets bundled as a digital product.

## 2. What ABBY builds

Engines: **Course + Commerce**. ABBY drafts module + lesson outlines; can deploy to Thinkific (`deploy-bp07-to-thinkific`). Optional MoR sale via platform Commerce.

## 3. What the author does

1) Open BP-07 builder. 2) Review module structure. 3) Optionally connect Thinkific subdomain. 4) Set price + activate.

## 4. What the reader experiences

Reader buys → receives Thinkific access OR Authors Bureau learner portal access → progresses through modules at own pace.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND (`course_id` set OR commerce signal).
