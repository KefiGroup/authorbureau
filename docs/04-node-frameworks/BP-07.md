## 1. What it is

A self-paced video / PDF course delivered as the book's mid-tier upsell. Sits between Workbook (BP-06) and Online Course (BA-10).

## 2. What ABBY builds

Engines: **Course + Commerce**. ABBY drafts module → lesson outline using the book's framework. Curriculum-aware sales copy via Standardized Sales Page Builder.

## 3. What the author does

1) Open BP-07 builder. 2) Approve curriculum. 3) Add lesson assets. 4) Set price. 5) Activate.

## 4. What the reader experiences

Reader buys → enrolment row in `course_enrollments` → `MemberPortalPage` access → progress tracked.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND (`course_id` set OR commerce signal).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $97–$297.

## 7. Dependencies

BP-06 (must precede per `mem://business/product-development-sequence`). Filename note: function path is legacy `generate-bp07-coaching`.
