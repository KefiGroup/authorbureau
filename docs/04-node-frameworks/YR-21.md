---

## 1. What it is

Speaker kit + topics list for booking the author for keynotes and panels.

## 2. What ABBY builds

Engine: **Asset store**. ABBY generates speaker bio, topic descriptions, demo reel page, speaking-fee guide.

## 3. What the author does

1) Open YR-21 builder. 2) Define topics + fees. 3) Add demo video link. 4) Activate.

## 4. What the reader experiences

Event organiser visits speaker page → fills inquiry form → booking conversation begins.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND commerce signal (speaking fee).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $5k–$50k per keynote.

## 7. Dependencies

BP-04 microsite for the speaker page.
