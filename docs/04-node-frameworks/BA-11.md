# BA-11 · Audiobook

_Version 3.2 · 2026-05-01_

**Category:** Build Authority  
**Scope:** Book-level  
**Primary edge function:** `supabase/functions/generate-ba11-audiobook/index.ts`

> Canonical source: see [Master Architecture Reference](../01-architecture/01-master-architecture-reference.md) §3 for the full registry.

---

## 1. What it is

Audiobook produced from the book's manuscript via ElevenLabs TTS, distributed via ACX (manual submission).

## 2. What ABBY builds

Engine: **TTS pipeline** (Podcast/Audiobook engine). Functions: `generate-ba11-audiobook` (planning), `ba11-audiobook-generate` (TTS render), `ba11-publish-audiobook` (distribution package), `ba11-voice-preview` (sample).

## 3. What the author does

1) Open BA-11 builder. 2) Pick voice. 3) Generate previews. 4) Render full chapters. 5) Save & Distribute → ACX guide generated. 6) Submit to ACX manually.

## 4. What the reader experiences

Reader buys on Audible / Apple Books → external fulfilment.

## 5. Readiness gate (`hasRequiredAssets`)

`narration_script_url` set OR `acx_guide_generated === true` OR `chapters[]` non-empty.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — Audible royalty share (typically 25–40 % of list).

## 7. Dependencies

ElevenLabs (platform-managed). ACX submission is manual.

## Technical Appendix

### 8. `content_json` schema

```typescript
{
  audiobook_id: string;
  voice_id: string;                  // ElevenLabs voice
  narration_script_url?: string;
  acx_guide_generated?: boolean;
  chapters: Array<{ id; title; script_markdown; audio_url?; duration_sec? }>;
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
