---

## 1. What it is

A live or evergreen webinar that delivers core book value and pitches a paid offer.

## 2. What ABBY builds

Engines: **Sessions + Email**. ABBY drafts webinar outline, slide-by-slide narrative, registration page copy, and reminder email sequence.

## 3. What the author does

1) Open BP-05 builder. 2) Set date + Zoom link (manual paste). 3) Approve registration page + emails. 4) Activate.

## 4. What the reader experiences

Reader registers → enrolled in reminder sequence → attends → CTA at the close → first purchase.

## 5. Readiness gate (`hasRequiredAssets`)

Generic gate — non-empty `content_json` passes.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Indirect (list growth) + direct (offer-at-close conversions).

## 7. Dependencies

BP-01 (reminder sequence), BP-04 (registration page).

## Technical Appendix

### 8. `content_json` schema

```typescript
{
  webinar_id: string;
  title; date; zoom_link;            // manual paste — Daily.co removed Sprint 30
  outline: Array<{ minute; topic; key_points }>;
  slides: Array<{ id; title; body_html }>;
  registration_page: { headline; body_html; cta_label };
  reminder_sequence_id?: string;     // FK → email_flows.id
  offer_node_id?: string;            // node to pitch at the close
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
