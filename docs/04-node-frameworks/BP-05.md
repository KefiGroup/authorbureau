# BP-05 · Webinars

_Version 3.0 · 2026-05-01_

**Category:** Brand  
**Scope:** Book-level  
**Edge function:** `supabase/functions/generate-bp05-webinars/index.ts`

---

## 1. What it is

A live or evergreen webinar where the author teaches one core idea from the book and pitches a paid offer.

## 2. What ABBY builds

Engines: **Sessions + Email**. ABBY drafts a webinar outline, slide titles, registration page copy, reminder sequence, and follow-up sequence. Sessions live in `consultation_sessions`-style records.

## 3. What the author does

1) Open BP-05 builder. 2) Set date/time + Zoom link (paste). 3) Review outline + slide titles. 4) Activate — registration page goes live, Email Engine schedules reminders.

## 4. What the reader experiences

Reader registers → receives confirmation + reminder emails → attends → receives recording + offer follow-up.

## 5. Readiness gate (`hasRequiredAssets`)

Generic gate — any non-empty `content_json`.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

High — webinar pitch typically converts to BA-10 / YR-19 / YR-23.

## 7. Dependencies

BP-01 (sequence delivery). Zoom link is pasted manually (no Zoom API integration).
