# BP-06 · Workbook

_Version 3.0 · 2026-05-01_

**Category:** Brand  
**Scope:** Book-level  
**Edge function:** `supabase/functions/generate-bp06-online-course/index.ts`

---

## 1. What it is

A printable / fillable PDF companion to the book — exercises, prompts, and worksheets readers complete to apply the book's framework.

## 2. What ABBY builds

Engines: **Course + Commerce**. ABBY drafts modular workbook content; PDF rendered by client. Listed for sale via the Commerce Engine; `purchases` records each transaction.

## 3. What the author does

1) Open BP-06 builder. 2) Review modules. 3) Set price (or free). 4) Activate — sale page + download flow goes live.

## 4. What the reader experiences

Reader buys via `<BuyNowButton>` → checkout via `create-checkout-session` → confirmation email with download link.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND (`pdf_url` set OR commerce signal — `stripe_price_id` / `price_usd > 0` / paid sales tier).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $9–$29.

## 7. Dependencies

BP-09 (book sales) for cross-push opportunities.
