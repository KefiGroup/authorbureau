_Version 3.2 · 2026-05-01_

**Category:** Brand Products  
**Scope:** Book-level  
**Primary edge function:** `supabase/functions/generate-bp06-workbook/index.ts`

> Canonical source: see [Master Architecture Reference](../01-architecture/01-master-architecture-reference.md) §3 for the full registry.

---

## 1. What it is

A printable / fillable PDF companion to the book — exercises, prompts, and worksheets readers complete to apply the book's framework.

## 2. What ABBY builds

Engines: **Course + Commerce**. ABBY drafts modular workbook content; PDF rendered by client (`workbook-pdf.ts`). Listed via Commerce Engine; `purchases` records each transaction.

## 3. What the author does

1) Open BP-06 builder. 2) Review modules. 3) Set price (or free). 4) Activate — sales page + download flow goes live.

## 4. What the reader experiences

Reader buys via `<BuyNowButton>` → checkout via `create-checkout-session` → confirmation email with download link.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND (`pdf_url` set OR commerce signal — `stripe_price_id` / `price_usd > 0` / paid sales tier).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $9–$29 per unit (per `mem://business/node-revenue-architecture-estimates`).

## 7. Dependencies

BP-09 cross-push for sales-page placement. Sprint 50 renamed the generator folder from `generate-bp06-online-course` → `generate-bp06-workbook`.

## Technical Appendix

### 8. `content_json` schema

```typescript
{
  title: string;
  modules: Array<{ id; title; exercises: Array<{ prompt; type: "freeform"|"checklist"|"matrix" }> }>;
  pdf_url?: string;                  // Supabase Storage path once rendered
  stripe_price_id?: string;
  price_usd?: number;
  delivery_url?: string;             // autofilled by trigger
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
