## 1. What it is

Author-hosted annual conference — premium tickets, sponsors, speakers.

## 2. What ABBY builds

Engines: **Commerce + Sessions**. ABBY drafts agenda, sales page, sponsor packages, speaker outreach.

## 3. What the author does

1) Open YR-26 builder. 2) Set venue + dates. 3) Set tier prices. 4) Activate.

## 4. What the reader experiences

Attendee buys ticket → receives agenda + venue info → attends.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND commerce signal.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — tickets $497–$2,997 + sponsor revenue.

## 7. Dependencies

Stripe; venue logistics manual.
