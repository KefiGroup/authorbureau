_Version 3.2 · 2026-05-01_

---

## 1. What it is

Long-form group programme combining cohort coaching, peer accountability, and live retreats.

## 2. What ABBY builds

Engines: **Sessions + Commerce**. ABBY drafts cohort outline, application form, sales page, Zoom schedule.

## 3. What the author does

1) Open YR-23 builder. 2) Define cohort + cadence. 3) Set price. 4) Activate.

## 4. What the reader experiences

Reader applies → accepted → buys → joins cohort.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND commerce signal AND (`session_type` OR `booking_url` — session-style).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $5k–$25k per seat.

## 7. Dependencies

Stripe; manual Zoom link.

## Technical Appendix

### 8. `content_json` schema

```typescript
{
  title: string;
  cohort_dates: { start; end };
  cadence: "weekly"|"biweekly"|"monthly";
  session_type: "virtual"|"hybrid";
  booking_url?: string;
  application_form_id?: string;
  stripe_price_id; price_usd;
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
