# BA-13 · Group Coaching

_Version 3.0 · 2026-05-01_

**Category:** Build  
**Scope:** Book-level  
**Edge function:** `supabase/functions/generate-ba13-group-coaching/index.ts`

---

## 1. What it is

A cohort-based group coaching programme — a fixed group meeting on a schedule for a defined duration.

## 2. What ABBY builds

Engines: **Sessions + Commerce**. ABBY drafts cohort outline, session schedule, sales page, application form.

## 3. What the author does

1) Open BA-13 builder. 2) Set cohort dates + Zoom link. 3) Set price. 4) Activate.

## 4. What the reader experiences

Reader applies → gets accepted → buys → receives schedule + Zoom links → joins live cohort.

## 5. Readiness gate (`hasRequiredAssets`)

`sessions[]` non-empty OR `schedule` string set.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct + cohort — typically $497–$2,997 per seat.

## 7. Dependencies

Stripe; manual Zoom link.
