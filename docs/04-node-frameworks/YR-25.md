> Canonical source: see [Master Architecture Reference](../01-architecture/01-master-architecture-reference.md) §3 for the full registry.

---

## 1. What it is

Formal certification programme that licenses others to teach the author's framework.

## 2. What ABBY builds

Engines: **Course + Commerce**. ABBY drafts certification curriculum, exam, licensing terms, sales page.

## 3. What the author does

1) Open YR-25 builder. 2) Approve curriculum + exam. 3) Set price + recurring licence fee. 4) Activate.

## 4. What the reader experiences

Practitioner buys → completes course → passes exam → receives certification + licence.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND commerce signal.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct + recurring — typically $2k–$10k upfront + annual licence.

## 7. Dependencies

Stripe; optional Thinkific delivery.
