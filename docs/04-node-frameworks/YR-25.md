A certification programme that licences others to teach the author's framework. Highest-margin Yield offer.

## 2. What ABBY builds

Engines: **Course + Commerce**. ABBY drafts certification curriculum, exam structure, licensing terms. `deploy-yr25-to-thinkific` for course host.

## 3. What the author does

1) Open YR-25 builder. 2) Define certification levels + curriculum. 3) Set price. 4) Activate.

## 4. What the reader experiences

Practitioner buys → completes certification → receives credential + use of trademark.
