_Version 3.2 · 2026-05-01_

**Category:** Build Authority  
**Scope:** Author-level  
**Primary edge function:** `supabase/functions/generate-ba15-media-pr/index.ts`

> Canonical source: see [Master Architecture Reference](../01-architecture/01-master-architecture-reference.md) §3 for the full registry.

---

## 1. What it is

Press release + targeted media outreach to land podcast interviews, book reviews, and editorial features.

## 2. What ABBY builds

Engine: **Asset store**. ABBY drafts press release (headline + body), media list, pitch emails, author bio.

## 3. What the author does

1) Open BA-15 builder. 2) Approve press release. 3) Approve outlets list. 4) Send pitches manually.

## 4. What the reader experiences

Reader discovers the author via a podcast guest spot, review, or feature.

## 5. Readiness gate (`hasRequiredAssets`)

Press release present (string OR object with both `headline` AND a body field) AND outlets list non-empty (`target_media_outlets` / `media_list` / `outlets`).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Indirect — discovery + authority signal.

## 7. Dependencies

BP-04 microsite as landing destination.

## Technical Appendix

### 8. `content_json` schema

```typescript
{
  press_release: string | { headline; body };  // or press_release_html
  target_media_outlets?: Array<{ name; type; contact_email; pitch_subject }>;
  media_list?: Array<...>;            // legacy alias
  outlets?: Array<...>;               // legacy alias
  pitch_email_template?: string;
  author_bio_short?: string;
  author_bio_long?: string;
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
