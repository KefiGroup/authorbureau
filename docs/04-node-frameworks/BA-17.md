# BA-17 · Bundles

_Version 3.0 · 2026-05-01_

**Category:** Build  
**Scope:** Book-level  
**Edge function:** `supabase/functions/generate-ba17-upsells/index.ts`

---

## 1. What it is

Multi-product bundles combining ≥ 2 existing offers (e.g. workbook + course) at a packaged price.

## 2. What ABBY builds

Engine: **Commerce**. ABBY drafts bundle offer + comparison table + checkout copy.

## 3. What the author does

1) Open BA-17 builder. 2) Pick ≥ 2 items from existing nodes. 3) Set bundle price. 4) Activate.

## 4. What the reader experiences

Reader sees bundle CTA on a single-product page → upgrades to bundle at checkout.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND `items.length >= 2` AND commerce signal.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — boosts AOV; typical bundle uplift 30–60 %.

## 7. Dependencies

Existing items (BP-06, BP-07, BA-10, etc).
