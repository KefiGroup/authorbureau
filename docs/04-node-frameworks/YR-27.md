# YR-27 · Fundraising

_Version 3.2 · 2026-05-01_

**Category:** Yield Revenue  
**Scope:** Author-level  
**Primary edge function:** `supabase/functions/generate-yr27-fundraising/index.ts`

> Canonical source: see [Master Architecture Reference](../01-architecture/01-master-architecture-reference.md) §3 for the full registry.

---

## 1. What it is

Fundraising offers — donations, cause-aligned product sales, charity tie-ins.

## 2. What ABBY builds

Engine: **Commerce**. ABBY drafts campaign page, impact narrative, donor tiers, thank-you sequence.

## 3. What the author does

1) Open YR-27 builder. 2) Define cause + tiers. 3) Set goal. 4) Activate.

## 4. What the reader experiences

Donor visits page → donates → receives thank-you + impact updates.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND commerce signal.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — variable, often pass-through to charity.

## 7. Dependencies

Stripe; legal compliance for non-profit framing where applicable.

### 8. `content_json` schema

```typescript
{
  title: string;
  cause: string;
  impact_narrative: string;
  donor_tiers: Array<{ name; amount_usd; perks; stripe_price_id }>;
  goal_usd: number;
  thank_you_sequence_id?: string;    // FK → email_flows.id
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
