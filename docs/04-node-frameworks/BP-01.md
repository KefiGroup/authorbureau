## 1. What it is

The author's master email list and the welcome sequence that turns a reader into a subscriber. Single source of truth for everything ABBY sends to the author's audience.

## 2. What ABBY builds

Engine: **Email Engine** (Resend). ABBY drafts a 3–10 step welcome sequence using the book's hook, theme, and call-to-action. Stored in `email_flows` + `email_flow_steps`; sequence ID written to `author_nodes.content_json.email_sequence_id`.

## 3. What the author does

1) Open BP-01 builder. 2) Confirm sender name + reply-to address (writes `author_email_settings`). 3) Review the auto-drafted sequence — edit subject lines and bodies. 4) Click Activate. The Email Engine starts enrolling new contacts immediately.

## 4. What the reader experiences

Reader hits a microsite or lead-magnet form → submits email → enters the welcome sequence step 1 within minutes → receives subsequent steps on cadence → can unsubscribe via per-author signed token at any time.

## 5. Readiness gate (`hasRequiredAssets`)

`email_sequence_id` set AND `steps[]` non-empty (new model), OR `sequence_steps[]` non-empty (legacy).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Indirect — feeds every paid offer downstream. Direct revenue when a sequence step contains a Buy CTA for BP-09 / BP-06 / BA-10.

## 7. Dependencies

Resend connector (platform-managed, always on). Recommended: BP-02 (lead magnet) for the entry point.

## Technical Appendix

### 8. `content_json` schema

```typescript
{
  email_sequence_id: string;        // FK → email_flows.id
  steps: Array<{                    // mirrored from email_flow_steps for fast read
    subject: string;
    body_html: string;
    delay_hours: number;
  }>;
  sequence_steps?: Array<...>;      // legacy shape, still accepted by gate
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
