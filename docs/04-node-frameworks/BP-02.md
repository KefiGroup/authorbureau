---

## 1. What it is

A 2–3-minute quiz / assessment that captures email in exchange for a personalised result. The book's #1 list-builder.

## 2. What ABBY builds

Engines: **Funnel + Email**. ABBY generates 8 questions, 5 result tiers, 3 headline variants per `mem://ai/lead-magnet-generation-specs`. Companion functions: `generate-bp02-social-pack` (distribution graphics) and `bp02-activate-funnel` (publishes the microsite).

## 3. What the author does

1) Open BP-02 builder. 2) Pick a template (6 visual templates available). 3) Approve quiz + results. 4) Pick the headline variant (Identity / Outcome / Curiosity). 5) Activate — public lead-magnet microsite goes live.

## 4. What the reader experiences

Reader sees gate → answers 8 questions → receives result tier (HTML inline + email follow-up) → enters BP-01 sequence (CRM score +10).

## 5. Readiness gate (`hasRequiredAssets`)

Generic gate — any non-empty `content_json` passes. The lead-magnet builder always writes substantial content on save.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Indirect — top-of-funnel for every downstream offer.

## 7. Dependencies

BP-01 (sequence to enrol into). Optional: BP-04 (microsite to embed CTA on).

## Technical Appendix

### 8. `content_json` schema

```typescript
{
  funnel_id: string;                // FK → funnels.id
  template_id: string;              // 1 of 6 visual templates
  headline_variant: "identity" | "outcome" | "curiosity";
  questions: Array<{ id; prompt; options: Array<{label;tier_weight}> }>;  // exactly 8
  result_tiers: Array<{ tier; headline; copy; recommended_offer }>;       // exactly 5
  social_pack_id?: string;          // FK → marketing_assets (when generated)
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
