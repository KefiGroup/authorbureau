## 1. What it is

Author's premium 1:1 coaching practice — typically monthly retainer or session packages.

## 2. What ABBY builds

Engines: **Sessions + Commerce**. ABBY drafts package descriptions, application form, sales page, intake email.

## 3. What the author does

1) Open YR-19 builder. 2) Define packages. 3) Set price + booking URL. 4) Activate.

## 4. What the reader experiences

Reader applies → discovery call → buys → schedules sessions via booking URL.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND commerce signal AND (`session_type` OR `booking_url` — session-style).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $497–$5,000 / month.

## 7. Dependencies

Stripe; external booking tool (Calendly / Zoom — link only).
