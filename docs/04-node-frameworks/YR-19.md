# YR-19 · 1-on-1 Coaching

_Version 3.0 · 2026-05-01_

**Category:** Yield  
**Scope:** Author-level  
**Edge function:** `supabase/functions/generate-yr19-coaching/index.ts`

---

## 1. What it is

Premium 1:1 coaching with the author — packages priced per call or per programme.

## 2. What ABBY builds

Engines: **Sessions + Commerce**. ABBY drafts package descriptions, intake form, scheduling copy. `coaching_packages` records each package.

## 3. What the author does

1) Open YR-19 builder. 2) Define packages (price, # sessions, deliverables). 3) Add booking URL (Calendly etc). 4) Activate.

## 4. What the reader experiences

Reader books → pays → receives intake form + Zoom link → coaching sessions begin.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND commerce signal AND (`session_type` OR `booking_url` set, since YR-19 is session-style).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $250–$1,500 per session or $2k–$10k per package.

## 7. Dependencies

Stripe; manual Zoom + booking link.
