# YR-19 · 1-on-1 Coaching

_Version 3.2 · 2026-05-01_

**Category:** Yield Revenue  
**Scope:** Author-level  
**Primary edge function:** `supabase/functions/generate-yr19-coaching/index.ts`

> Canonical source: see [Master Architecture Reference](../01-architecture/01-master-architecture-reference.md) §3 for the full registry.

---

## 1. What it is

Author's premium 1:1 coaching practice — typically monthly retainer or session packages.

## 2. What ABBY builds

Engines: **Sessions + Commerce**. ABBY drafts package descriptions, application form, sales page, intake email.

## 3. What the author does

1) Open YR-19 builder. 2) Define packages. 3) Set price + booking URL. 4) Activate.

## 4. What the reader experiences

Reader applies → discovery call → buys → schedules sessions via booking URL.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND commerce signal AND (`session_type` OR `booking_url` — session-style).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $497–$5,000 / month.

## 7. Dependencies

Stripe; external booking tool (Calendly / Zoom — link only).

## Technical Appendix

### 8. `content_json` schema

```typescript
{
  title: string;
  packages: Array<{ name; sessions_per_month; duration_min; price_usd; stripe_price_id }>;
  session_type: "discovery"|"intensive"|"retainer";
  booking_url: string;
  application_form_id?: string;
  intake_email_template: string;
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
