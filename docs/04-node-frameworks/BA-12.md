# BA-12 · Membership

_Version 3.0 · 2026-05-01_

**Category:** Build  
**Scope:** Book-level  
**Edge function:** `supabase/functions/generate-ba12-membership/index.ts`

---

## 1. What it is

A recurring membership tied to the book's themes — monthly content, community, exclusive sessions.

## 2. What ABBY builds

Engine: **Commerce (recurring)**. ABBY drafts membership offer + monthly content calendar + welcome sequence. Subscriptions in `subscriptions`.

## 3. What the author does

1) Open BA-12 builder. 2) Define membership benefits. 3) Set monthly price (Stripe price ID). 4) Activate.

## 4. What the reader experiences

Reader buys → recurring Stripe subscription → ongoing access to `membership_content` → can cancel via `customer-portal`.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND `stripe_price_id` set.

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct + recurring — typically $19–$97 / month.

## 7. Dependencies

Stripe (platform). Optionally BP-01 for member nurture.
