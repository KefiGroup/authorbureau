## 1. What it is

A recurring-revenue community / content subscription anchored to the book's framework.

## 2. What ABBY builds

Engine: **Commerce (recurring)**. ABBY drafts membership tiers, content calendar, sales page.

## 3. What the author does

1) Open BA-12 builder. 2) Define tier benefits. 3) Set Stripe recurring price. 4) Activate.

## 4. What the reader experiences

Reader subscribes via `<BuyNowButton>` → recurring charge → `membership_content` access until cancellation.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND `stripe_price_id` set (recurring price required).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct recurring — typically $19–$97 / month.

## 7. Dependencies

Stripe (platform).
