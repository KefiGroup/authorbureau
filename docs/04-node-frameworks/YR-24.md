# YR-24 · Retreats

_Version 3.2 · 2026-05-01_

**Category:** Yield Revenue  
**Scope:** Author-level  
**Primary edge function:** `supabase/functions/generate-yr24-retreats/index.ts`

> Canonical source: see [Master Architecture Reference](../01-architecture/01-master-architecture-reference.md) §3 for the full registry.

---

## 1. What it is

In-person multi-day retreats — premium experience tied to the book's transformation.

## 2. What ABBY builds

Engines: **Sessions + Commerce**. ABBY drafts retreat itinerary, sales page, application form.

## 3. What the author does

1) Open YR-24 builder. 2) Set venue + dates. 3) Set price. 4) Activate.

## 4. What the reader experiences

Reader applies → accepted → buys → travels to venue.

## 5. Readiness gate (`hasRequiredAssets`)

`title` set AND commerce signal AND (`session_type` OR `booking_url` — session-style).

_Source: `supabase/functions/_shared/node-readiness.ts`._

## 6. Revenue model

Direct — typically $3k–$15k per seat.

## 7. Dependencies

Stripe; venue logistics manual.

## Technical Appendix

### 8. `content_json` schema

```typescript
{
  title: string;
  venue: { name; city; country };
  dates: { start; end };
  itinerary: Array<{ day; activities: string[] }>;
  session_type: "in_person";
  booking_url?: string;
  stripe_price_id; price_usd;
}
```

> Stored at `author_nodes.content_json` for this node ID. The readiness gate (§5) reads from this object.
